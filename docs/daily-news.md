# 每日资讯

在左侧选择「每日资讯」。可以建立多个订阅，比如游戏早报、动漫动态或综合资讯，各自设置方向、目标和时间。

1. 填写订阅名称，选择单选或多选方向。在「细化关注内容」中，为每个分类分别添加主题，例如游戏中的「三角洲」、体育中的「张雪摩托」。每类可以添加多个主题，并修改或删除；切换分类会保留已填写主题，只有选中的分类参与检索。没有细分主题时按整个方向检索，下面的公开关键词可提供额外的检索补充。
2. 在「推送计划」中添加多个固定时间，例如 09:00、12:30、20:00；也可以添加时间段，例如 09:00–18:00、每隔 60 分钟推送。两种方式可组合，每个时间点或时间段均可编辑、删除。另行选择星期和每期条数上限。高级筛选支持回看 24 / 48 / 72 小时、逗号分隔的排除词，以及最多五个公开来源域名。
3. 添加已经在「会话」页确认身份的目标。可以选群和朋友，也可以选择多个目标。目标必须处于运行状态并完成窗口校准，才能发送。
4. 保存订阅，点击「生成预览」。预览会真实检索公开网页并整理来源摘录，不会发送消息。简洁简报使用直接的资讯语气；当前人格用于调整摘录前的语气。
5. 核对内容后点击「立即推送」，或开启「定时推送」并保存。右侧「推送记录」展示每个目标、每段内容及回执状态。

资讯采集使用已配置的模型凭据和公开检索服务。查询仅包含方向、公开关键词、日期和来源域名，不会把收件人、聊天记录或身份写进查询。网页内容只是资料，没有修改订阅或执行操作的权限。

检索索引时间不代表文章发布时间。没有明确发布时间的来源标注「发布时间未核实」；已知过期、未来或被排除的来源不会进入简报。部分方向检索失败会显示缺失说明，不会补造新闻。多选方向按轮次取结果，避免第一个方向占满所有条数。

电脑、微信和助手后台须保持运行；不会自动解除全局暂停、观察模式或目标暂停。普通聊天回复优先。恢复运行时只补最近且仍在两小时窗口内的一轮；下一轮到来后停止旧期尚未发送的内容，已进入原生发送流程的内容继续核对回执。

固定时间和重叠时间段落在同一分钟时只触发一次。时间段从开始时间起按间隔计算；结束时间恰好落在步长上时也包含该轮。例如 09:00–11:00、间隔 60 分钟为 09:00、10:00、11:00 三轮。22:00–02:00 表示跨午夜；星期沿用时间段的开始日，例如选择周五，会包含周六凌晨的该段计划。

细分主题独立检索并检查相关性，预览和发送文本均可识别分类、主题。每个分类最多 8 个主题，总计 24 个；未选分类保留的设置也计入总数。多轮采集在选取本期条数之前过滤目标共同的已收来源和正在核对的发送意图，优先选择尚未推送的内容。对不同目标仍分别去重，所以某个目标实际收到的条数可能少于所设上限。

同一目标收到并确认过的来源会去重；多个订阅共享这份记录。回执不明的内容会单独保留核对状态，不会自动重发。取消或删除会停止后续内容；已经进入微信发送流程的那一段会继续核对回执，已经发送的消息不会撤回。新订阅默认停用且没有目标，已有设置和私人文件在升级时保留。
