# 每日资讯订阅与微信推送实施计划

日期：2026-11-11。基线：已发布的 v0.3.15。用户已授权先写计划、生成设计稿并自主完成开发，无须中途确认。

## 目标与范围

在现有左侧导航中新增「每日资讯」。用户可以创建多个订阅，单选或多选资讯方向，补充关键词，设置发送时间和星期，并把每日简报推送到已确认身份的微信群或个人会话。资讯来自真实联网检索，提供来源和时间说明；预览、立即推送、定时推送、发送记录都必须可用。

沿用现有 Electron、React、TypeScript、Python 技术和共享页面外壳。保留背景、头像、其他页面、圆润按钮、顶部居中提示、页面切换动效。页面标题不加副标题。默认订阅关闭、默认不选择收件人；升级后不会擅自向现有群发送消息。

## 产品行为

1. 方向覆盖游戏、动漫、音乐、电竞、美食、国际、科技、人工智能、数码、影视、财经、体育、旅游、生活、教育、科学、汽车、健康等，并支持自定义公开关键词。单选、多选都是真实可保存状态。
2. 每个订阅独立配置名称、目标会话、每天时间、星期、资讯条数、回看时长、排除词、来源域名、简洁简报或当前人格口吻、是否附链接。北京时区固定显示。
3. 「生成预览」保存当前草稿后异步检索；预览不发送。「立即推送」仅发送当前已生成且与设置一致的内容，目标和条数在操作旁明确展示。无内容、无目标、账号变化、暂停、校准缺失均显示具体状态。
4. 每天时间到后后台自动生成并发送；启动后只补当前两小时内的任务，过期任务显示错过，不堆积旧简报。订阅编辑、删除或停用会取消尚未开始的自动发送。
5. 来源中的抓取时间不冒充文章发布时间。严格标注发布时间未知；可疑旧闻不包装为今日新闻。失败不生成虚构标题、摘要或链接，部分方向失败可展示已有结果和缺失方向。
6. 相同来源链接、近似标题去重；已确认发给该目标的资讯不重复推送。预览不计为已发送。每条发送通过原有身份核对、窗口唤醒、输入校验和回执管线，收到回执才算成功。
7. 全局暂停、观察模式、目标独立暂停、窗口未校准都不会被资讯功能悄悄解除。后台收集不阻塞普通聊天。多目标逐个显示成功、等待、失败或回执不明，避免一个目标故障阻断其他目标。
8. 数据保存在本机私有运行目录；查询只含公开方向、关键词、日期和来源，不含微信收件人、聊天历史或身份。公开版继续只保留两句默认人格。

## 页面与设计

先用现有工作台截图生成「每日资讯」完整设计参考，再使用现有组件真实实现。参考画板 1860×1200，共享侧栏 290px，主区左边距 38px；实际实现服从现有 CSS 的同等缩放。侧栏新增一项，其他顺序和位置规则不改。

主区上方为订阅选择、新建、启用状态；中部左侧为方向选择、关键词与推送计划，右侧为简报预览 / 推送记录；底部固定操作条与侧栏和右边框衔接。选中方向使用桃色胶囊和勾选，星期与目标支持多选。设计参考采用清晰可辨的通用示例，运行页面无真实结果时显示空状态。
