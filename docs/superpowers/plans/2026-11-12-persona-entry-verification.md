# v0.3.19 人格试聊入口与十项功能复核

## 查明的问题与修改

v0.3.18 的人格试聊已有实际模型链路，本机正式安装版点击后取得了一次真实模型回复。问题是入口与导入、导出混在工具栏中，辨识度较低，且回复气泡使用浅底浅字。

v0.3.19 将人格页改为固定的「人格编辑 / 人格试聊」分段切换，选中项高亮。编辑稿、模块顺序与启停、导入、导出、预览及保存仍沿用原流程。试聊使用当前草稿，不增加人格内容限制。

回复气泡改为稳定的深色底和浅色文字。另修复小窗口中启用模块概况被挤到零高度、试聊清空按钮溢出，以及合法长模块名称覆盖相邻行的问题。模块概况可滚动，紧凑窗口改为单列，长名称仅在展示处截行，完整名称可悬停查看，原文保持不变。

## 十项目标逐项复核

| 目标 | 实际入口 | 本轮验证 |
| --- | --- | --- |
| 未来计划 | 任务中心 → 计划总览 | 实际桌面服务返回资讯/关怀时间及条件窗口，筛选、编辑返回原订阅通过。 |
| 运行诊断 | 运行设置 → 运行诊断 | 本地检查及网络探测交互通过；实际模型服务和公共搜索均正常响应。 |
| 同事件合并 | 每日资讯 → 高级筛选 → 事件合并与偏好管理 | 合并来源元数据、关联来源链接和开关通过；数字、版本与标点去重专项通过。 |
| 细分主题条件 | 每日资讯 → 高级筛选 → 每个主题的检索条件 | 别名、关注、排除条件实际保存，停用主题配置保留。 |
| RSS / Atom | 每日资讯 → 高级筛选 → 来源与公共 RSS / Atom | 模式、主题绑定、优先级、启停与移除保存通过；实际抓取两处公开源得到 60/10 项。 |
| 人格试聊 | 人格 → 顶部「人格试聊」 | 本机真实模型回复；隔离环境实际编译器/模型桥接、多轮、取消、失败恢复、换号隔离和草稿传递通过。 |
| 临时休息 | 会话详情，或工作台监听对象旁咖啡图标 | 实际桌面服务开始休息、倒计时及提前结束通过；恢复权限专项通过。 |
| 会话总结 | 记忆与陪伴 → 会话总结 | 读取留存记录、生成、编辑及原发送队列桥接通过；队列接受与微信回执仍分别标明。本轮未再次向微信发送测试消息。 |
| 资讯反馈 | 预览文章下方；高级筛选内偏好管理 | 文章反馈保存、修改、撤销及来源/主题作用域通过。 |
| 用量统计 | 任务中心 → 用量统计 | 真实 SQLite 用量读取、价格保存、费用估算、跨标签草稿与退出保护通过。 |

## 回归与边界

- 人格入口、编辑草稿保留、真实请求参数和无正式写入检查通过。
- 16 个普通模块与 48 个模块、99–100 字合法长名称分别完成四档等效 CSS 视口检查；同时检查模块概况高度、面板内部滚动宽度、清空按钮边界和文字行边界，避免仅检查整个文档宽度。
- 正式安装的 v0.3.19 使用隔离测试账号、实际冻结桌面服务及本机模型测试端点，再次通过两轮草稿试聊与总结队列检查，并调用 Electron 实际缩放接口完成 100/125/150/200% 检查；启用模块概况非零、清空按钮在面板内、没有面板横向溢出。
- 回复正文在深浅背景下的最小测量对比度为 12.89:1。
- 既有试聊生命周期检查通过：前置服务拒绝、24 条已完成上下文保留、取消、重置、改稿、换号及迟到结果隔离。
- 新增功能后端专项 195 项通过，写操作保护专项 21 项通过；TypeScript 与生产构建通过。
- 完整 Python 回归本轮为 2225 项通过、3 项跳过；其中生命周期测试为避免关闭正在运行的本机助手而跳过，更新安装前停止助手后单独补测 **1 项通过**。合计 2226 项通过；其余两个跳过项需未安装的可选官方 Harness 测试依赖。
- 独立复审提出的三处布局问题均分别重现，补充回归后修复；没有把「按钮存在」当作全部功能完成的证据。

公开版依旧只有两句通用默认人格，不包含个人模块、聊天、凭据、数据库及原始实机记录。安装交付与远端产物校验由发布流程核对；下载见 [v0.3.19](https://github.com/GGBond2424648901/shiguang-wechat-assistant/releases/tag/v0.3.19)。
