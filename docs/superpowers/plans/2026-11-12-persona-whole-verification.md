# v0.3.20 整套人格试聊验收记录

对应[实施计划](2026-11-12-persona-whole-trial.md)。

## 可见变化

- 右侧标题「整套人格试聊」及动态启用数量，明确使用当前完整草稿。
- 试聊左侧为「人格组成」列表，没有单模块选中高亮、序号及排序按钮；启用、停用状态保持可见。
- 搜索仅改变列表展示，不改变提交给模型的模块范围。
- 返回编辑仍保留原来的模块选择、文字草稿和启停修改；只有编辑页显示选择与整理顺序的操作。
- 原「按列表顺序生效」提示改为「全部启用模块共同生效，排列仅用于整理」。

## 组合逻辑

试聊与正式回复共用原人格编译器，所有启用原文完整参与，停用原文排除。模块化人格仅增加一句组合说明：启用模块共同描述一个完整人格，排列用于整理，不表示权重或优先级，按当前对话综合运用。

没有引入数字权重、关键词挑选、模块裁剪、自动覆盖或随机打乱。原文、保存顺序和个人文件不被改写。非模块化的旧人格编译结果保持一致。

## 已验证

- 新增正序、倒序的多模块回归：三份启用原文全部保留，停用原文排除，试聊与正式编译文字一致，没有向微信排队发送。
- 人格试聊后端专项 **17 项通过**；完整 Python 回归 **2227 项通过、3 项跳过**。其中生命周期测试为避免停止本机已运行的助手而跳过，安装更新前补测 **1 项通过**，合计 2228 项通过；其余两项需要可选官方 Harness 测试依赖。
- 普通 16 模块和 48 个长名称模块的四档界面回归通过；没有单选高亮或排序控件，动态数量准确。搜索到一个模块时，实际请求仍提交完整草稿和全部启用项。
- 返回非首个编辑模块的回归覆盖原选择保留；试聊期间仍不显示单模块选择。
- 既有取消、拒绝恢复、重置、改稿、换号及迟到结果隔离通过。
- 真实 Electron、桌面服务、编译器和本机隔离 HTTP 模型端点完成多轮试聊；核对实际收到的模型请求，全部启用模块块和同级说明存在，即使左侧只搜索出一项。总结队列及实际四档缩放同时通过。

本轮证明输入完整、组合语义及界面范围正确。语言模型对长上下文的关注程度仍可能受位置、重复和冲突条款影响；同级说明不是消除位置效应或保证每句话平均体现所有模块的承诺。公开版仍仅保留两句通用默认人格，私人模块、聊天、凭据和数据库不进入公开包。
