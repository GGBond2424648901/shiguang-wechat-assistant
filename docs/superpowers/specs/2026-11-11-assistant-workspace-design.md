# 拾光 v0.3.18：任务中心与十项体验优化

用户已确认全部十项目标和页面分配，并要求先规划、再自主开发，不中途询问。基线为公开版 v0.3.17。开发使用独立公开源码检出，不覆盖个人旧工程或私人人格。

## 页面与交付

仅增加一个左侧导航「任务中心」，放在每日资讯之后。任务中心有计划总览、执行记录、用量统计；运行设置增加运行诊断；资讯页增加事件合并、主题条件、来源管理与偏好反馈；人格页增加试聊；会话和工作台增加临时休息；记忆与陪伴增加会话总结。

所有页面保持现有 React/Electron 技术、背景、头像、圆润控件、过渡和固定内容边距，标题无副标题，底部与侧栏/窗口边框连接。新增页面先生成参考稿，再实现真实 DOM。参考稿中的示例数据不写入正式用户配置。

## 十项验收

1. **未来计划**：显示未来 24/48/72 小时的真实资讯、定时关怀时刻、目标及阻塞原因；主动聊天只能标为条件触发和预计窗口，不保证某分钟发送。编辑入口回到原页面，无重复配置存储。
2. **运行诊断**：本地检查账号、后台、凭据是否存在、窗口校准和发送阻塞；联网检查由用户点击发起，区分未检查/通过/异常。诊断不发送微信测试消息，不改运行开关，不输出密钥。
3. **同一事件**：在现有 URL/相似标题去重之上合并高度可信的同事件转载，保留可追溯来源；不同版本、比分、日期、实质新进展及观点不能仅因主题相同被吞掉。允许关闭。
4. **主题条件**：每个主题可配置别名、关注点、排除词；作用域只限该主题，不改写用户输入和人格。旧 categoryTopics 数据兼容。完整保存、预览、定时检索均生效。
5. **来源订阅**：订阅公开 HTTP(S) RSS/Atom，校验 URL、大小、超时、重定向、XML 实体及内网访问；可启停、排序/优先，失败可解释。保持现有联网搜索，不能把搜索结果冒充直接订阅。
6. **人格试聊**：真实模型多轮对话，可使用当前编辑稿；测试历史隔离，展示实际启用模块概况，不写正式记忆，不向微信发送。离开、换号、重置与并发请求不会串结果。
7. **临时休息**：按会话手动选择时长，显示倒计时、可取消；到期只恢复本次暂停前的模式。手动暂停、账号/身份变化、删除目标、后台重启均不能错误开启会话。沿用原生发送边界，未知回执不重发。
8. **会话总结**：按已授权会话和北京时间范围读取现存记录，输出讨论重点、待办和约定时间；不足/截断明确显示。先预览，显式点击才使用现有队列发送；任务稳定编号防重复，身份与模式再次核对。
9. **资讯反馈**：喜欢/无关/重复可修改、撤销，偏好按账号和订阅隔离、可见。只影响该订阅筛选，不改写人格，不伪造点赞等平台互动。
10. **用量统计**：真实累计模型调用、输入/输出 tokens（服务未提供则标缺失）、检索次数、耗时及失败；显示当前待处理数和最早任务的实际等待秒数，后台断开或时间未知时明确标记。用户配置单价估算费用。统计不保存 prompt、回复正文、密钥或私聊身份，不做硬预算限制。

## 架构决策

沿用 Python 桌面服务白名单 RPC、账号隔离的数据目录、SQLite/私有写入和现有守卫队列。新增职责模块，不把所有逻辑塞入 DesktopService。耗时工作使用有界后台任务，RPC 快速返回任务 ID，UI 轮询并清理，不占满本地界面服务。

采用三个独立模块并行实施，根代理负责公共路由、任务中心/诊断 UI、临时休息 UI、共享导航和集成。所有网络/模型内容按不可信资料处理。公共发布仍仅两句默认人格，本机数据保留。

备选方案：将所有功能塞到工作台会使信息拥挤；每个功能独立导航会增加入口。用户已选择的方案为一个任务中心加原页面扩展。

## 发布与证据

功能测试、模型与 RSS 故障测试、真实 Electron 交互与缩放检查、冻结模块比对、公开包隐私扫描通过后，构建 v0.3.18 源码和安装包，同步本机启动文件并发布 GitHub。保留真实检索、试聊和文件传输助手发送验证；不自动启用用户已有群。
