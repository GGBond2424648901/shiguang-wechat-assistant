# 任务中心与进阶功能

v0.3.18 在保留原有页面的基础上，只增加一个左侧入口「任务中心」，快捷键为 Alt+1–8。

## 任务中心

「计划总览」可切换未来 24、48、72 小时，按任务类型和会话筛选。资讯和定时关怀显示实际计划时间；主动聊天显示条件和预计评估窗口，是否开口仍取决于空闲、概率、安静时段和会话状态。未启用、暂停和待执行会分别标明。

点击「编辑」返回该订阅或会话原来的设置入口。原页面有未保存草稿时先处理草稿，任务中心不另存一套规则。

「执行记录」汇总已有资讯和关怀结果。已排队、部分确认、结果未知和微信回执已确认含义不同；已排队不代表成功发送。

「用量统计」按当前账号展示真实模型调用、检索及订阅抓取次数、服务返回的输入/输出 tokens、请求耗时和失败数。当前队列的数量和最早等待时间另行显示；后台或时间不可核实时明确标记。统计从本版开始积累，不会补造历史用量。

可以填写每百万输入/输出 tokens 的单价。费用只是按填写价格计算的估算，未配置单价或服务没有返回完整用量时不冒充完整账单；这里不设置硬性消费限制。

## 运行诊断

「运行设置 → 运行诊断」提供本地条件检查和主动联网检查。

- 本地检查后台、账号、凭据是否可用、窗口校准、暂停及队列条件。
- 点击「检查模型与联网」后实际探测模型连接和公共检索；未执行、缺凭据、异常、超时分别说明。
- 诊断保持当前运行模式，不向微信发送测试消息。复制诊断结果前可自行核对内容。

## 临时休息

在会话详情选择「临时休息」，或使用工作台监听对象旁的咖啡图标。可选常用时长，也可自定义分钟数；开始后显示剩余时间，并可提前结束。

到期会再次核对账号、会话身份、原运行模式和之后发生的手动操作。原本暂停或只观察的会话不会因此自动开启；新的手动暂停、身份变化和未知发送恢复状态优先。休息沿用现有暂停处理，过期的待回复内容不会无条件积压补发。

## 人格试聊

在「人格」页选择试聊，使用当前启用模块和编辑稿与真实模型进行多轮测试。试聊上下文单独保存，不写入正式会话记忆，也不向微信发送。

可以取消本次生成、清空试聊或返回编辑。取消后续一轮会保留已经完成的对话；修改人格、重置或换账号后，旧结果会失效。试聊会产生正常的模型调用和用量。

## 会话总结

「记忆与陪伴 → 会话总结」中先选择会话，再选择北京时间范围，生成讨论要点、行动事项和约定日期。

总结只使用当前会话本机实际保留的文字记录，展示采用条数、覆盖时间及截断情况。缺失或未保留的历史不会补造，图片和表情也不会凭文字记录猜内容。

生成后先看预览。需要发到所选会话时，可编辑发送正文再明确点击发送；当前发送正文上限为 400 字，较长内容需要自行精简。会话身份、模式和发送条件会再次核对。结果不确定时保留原请求核对，不能改一份正文盲目重发；最终成功以微信回执为准。

## 资讯主题、来源与反馈

「每日资讯」中，每个细分主题可以设置别名、关注点和排除词。别名与原主题共同识别；关注点至少命中一项，排除词只作用于所属主题。全局关键词和全局排除词仍单独生效。

可选公开检索、RSS / Atom 或两者组合，添加公开订阅地址并设置启停、绑定方向/主题和优先级。搜索与直接订阅的采集方式会分别标明，同一 URL 经两种方式获得时保留对应来源信息和优先级。来源失败时会显示说明。

直接订阅支持常见 RSS 2.0、Atom 1.0 和标准 HTTP(S) 地址；当前仅接收 UTF-8 等无 NUL 的 XML，非标准端口、超长内容、不安全地址和实体声明会报错。部分平台没有可直接使用的公开订阅源，可以继续使用公开检索。

「合并同一事件」采取保守判断，主要关联高度一致的转载，保留关联来源。不同版本、比分、日期、数值、观点和实质新进展会保留；改写较多的报道可能仍分别显示。仅修改句末句号、感叹号会继续按重复内容处理。

每条资讯可反馈喜欢、无关或重复，并在偏好管理中修改或撤销。偏好按账号和订阅分开，只影响对应订阅的筛选与排序，不改写人格。已经完成的真实发送记录保持原样。
